## 2. Dashboard 首页 (/)

### 状态卡片

```
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│ App 状态  │  │ BLE 状态  │  │ 小车状态  │  │ 工单状态  │
│ ● 在线   │  │ 模拟模式  │  │ 空闲      │  │ 无       │
└──────────┘  └──────────┘  └──────────┘  └──────────┘
```

卡片状态值：

| 卡片 | 可能的值 |
|------|---------|
| App 状态 | 在线 / 离线 |
| BLE 状态 | 已连接 / 未连接 / 模拟模式 |
| 小车状态 | 空闲 / 手动 / 自动 / 急停 / 故障 |
| 工单状态 | 无 / 执行中 / 已完成 |

### 概览数据

- 今日工单数 / 完成率
- 最近命令状态
- 当前报警
- 最近 7 天工单趋势折线图 (Recharts)

## 3. 工单管理页 (/orders)

### 工单列表

表格列：工单编号 | 盘柜名称 | 目标坐标 | 操作员 | 状态 | 创建时间 | 操作

筛选：按状态筛选、按日期范围

操作按钮：新建 | 编辑 | 删除 | 启动 | 暂停 | 继续 | 取消 | 查看详情

### 工单状态流转

```
draft → pending → dispatching → running → completed
                                       → paused → running
                                       → failed
                      → cancelled
```

### 新建/编辑工单表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 工单编号 | 自动生成 | - | WO-YYYYMMDD-NNN |
| 盘柜名称 | 文本输入 | ✅ | |
| 目标 X | 数字输入 | | 安装坐标 |
| 目标 Y | 数字输入 | | 安装坐标 |
| 目标节点 | 下拉选择 | | A1-A10 等预设点位 |
| 指派操作员 | 下拉选择 | | 从 workers 表选择 |
| 备注 | 多行文本 | | |

### 工单详情页 (/orders/[id])

```
基本信息区
├── 工单编号、盘柜名称、目标坐标
├── 绑定操作员、当前状态
└── 创建时间、开始时间、完成时间、耗时

命令回执记录
├── cmd_id | 类型 | 状态 | App ACK | 小车 ACK | 时间
└── ...

状态时间线
├── 2026-05-21 14:00 创建工单
├── 2026-05-21 14:05 下发执行
├── 2026-05-21 14:05 App 已接收
├── 2026-05-21 14:05 小车开始执行
└── 2026-05-21 14:07 执行完成 (耗时 120s)

报警记录
├── 无 / 报警列表
```

## 4. 实时监控页 (/monitor)

### 布局

```
┌──────────────────────────────────────────────────────────────┐
│ ⚠ 安全状态横幅：正常 / 急停中 / BLE 断开 / App 离线          │
├────────────────────────────────┬─────────────────────────────┤
│                                │  实时状态面板                │
│                                │  ─────────────              │
│     电气室平面图 / 路径图        │  当前模式：manual            │
│                                │  运动状态：idle              │
│     ● 小车位置                  │  推杆状态：idle              │
│     ─ 运动轨迹                  │  估计高度：80mm             │
│     ✕ 目标点                    │  电池电压：11.8V            │
│     ▲ 方向箭头                  │  障碍距离：25cm             │
│                                │  BLE RSSI：-45dBm           │
│                                │  App 在线：是               │
│                                │  最后更新：14:05:32         │
├────────────────────────────────┴─────────────────────────────┤
│ 命令回执日志                                                  │
│ cmd_001 | order.start | ✅ App 已确认 | ✅ 小车已执行 | 14:05 │
│ cmd_002 | order.pause | ✅ App 已确认 | ⏳ 等待      | 14:06 │
└──────────────────────────────────────────────────────────────┘
```

### 地图画布 (MonitorCanvas)

使用 HTML Canvas 绘制：
- 底图：电气室平面图网格
- 小车位置：蓝色三角形 + 方向
- 运动轨迹：半透明折线（最近 500 点）
- 目标位置：红色标记
- 工单进度百分比

数据来源：Socket.IO `server:telemetry` 事件，requestAnimationFrame 刷新。

### 模拟模式显示

嵌入式未完成时：
- 显示"模拟模式"标签
- 模拟小车沿预设路线移动
- progress_pct 按时间递增
- 到 100% 后自动完成工单

## 5. 人员管理页 (/workers)

表格列：工号 | 姓名 | 角色 | 联系电话 | 创建时间 | 操作

操作：新建 | 编辑 | 删除 | 重置密码

角色选择：operator（操作员）/ admin（管理员）

## 6. 报警日志页 (/alarms)

表格列：时间 | 报警代码 | 等级 | 描述 | 来源 | 关联工单 | 是否已处理

筛选：按等级、按代码、按日期范围

等级颜色：
- info → 蓝色
- warning → 黄色
- critical → 红色

## 7. 历史统计页 (/history)

图表（使用 Recharts）：
- 工单完成数量：最近 7 天趋势柱状图
- 工单平均耗时：折线图
- 报警次数统计：按类型饼图
- 操作员完成数量：横向柱状图

数据操作：
- 日期范围选择
- CSV 导出

## 8. 系统设置页 (/settings)

| 配置项 | 说明 |
|--------|------|
| Socket.IO 端口 | 默认 3000 |
| 遥测采样间隔 | 默认 5000ms |
| 命令超时时间 | 默认 3000ms |
| 最大重试次数 | 默认 3 |
| JWT 密钥 | 认证用 |
| 默认管理员密码 | 初始化用 |
