### 连接状态横幅 (ConnectionBanner)

始终显示在顶部：

| 信息 | 颜色规则 |
|------|---------|
| PC 连接状态 | 在线=绿色，离线=红色 |
| BLE 连接状态 | 已连接=绿色，未连接=灰色，模拟模式=蓝色 |
| 当前模式 | 手动=蓝色，自动=绿色，急停=红色 |

### 虚拟摇杆 (Joystick)

- Canvas 绘制圆形摇杆
- 触摸拖动控制方向
- 输出 dx, dy 归一化值 (-1 到 1)
- 发送频率：100ms 一次
- 被接管/急停时禁用（灰色遮罩 + 锁定图标）

### 推杆控制 (LiftControl)

- 上升按钮：长按持续上升，松手停止
- 下降按钮：长按持续下降，松手停止
- 停止按钮：立即停止
- 实时显示估计高度（mm）
- 进度条可视化

### 急停按钮 (EstopButton)

- 全宽红色大按钮，始终可见
- 不受控制权限制，任何时候都能按
- 触发后手机震动 + 确认弹窗
- 发送 BLE estop + Socket.IO 报警

### 速度档位

- 3 档：1档(慢) / 2档(中) / 3档(快)
- 对应 spd 值：1 / 2 / 3
- 默认 2 档

默认值：

| 配置 | 默认值 |
|------|--------|
| serverUrl | `http://192.168.1.100:3000` |
| simulateMode | `true` |
| bleNamePrefix | `ESP32` |
| serviceUUID | `0000FFE0-...` |
| cmdCharUUID | `0000FFE1-...` |
| stsCharUUID | `0000FFE2-...` |
| logCharUUID | `0000FFE3-...` |
| telemetryInterval | `500` (ms) |
| joystickInterval | `100` (ms) |
